# IBVAP — Actual Backend Implementation Specification

## Objective
Implement the real FastAPI backend and API layer.

## Structure
```text
backend/
├── app/
│   ├── main.py
│   ├── core/
│   ├── api/
│   ├── models/
│   ├── schemas/
│   ├── services/
│   ├── repositories/
│   ├── websocket/
│   └── workers/
├── alembic/
└── tests/
```

## Required APIs
Implement actual endpoints for:
- authentication
- cameras
- streams
- zones
- events
- alerts
- ANPR
- face recognition
- analytics
- users
- system health

## Event Flow
```text
AI/Edge event
→ validation
→ event service
→ PostgreSQL
→ alert rule evaluation
→ WebSocket broadcast
```

## Authentication
Implement:
- login
- password hashing
- access token/session
- role checks
- protected routes

## WebSocket
Provide a real event channel for:
- new alert
- new event
- camera online/offline
- system health changes

## Acceptance Criteria
- `/health` works
- database migrations work
- authenticated endpoints reject unauthorized requests
- events persist
- alerts are broadcast to connected clients
- API documentation is generated by FastAPI
