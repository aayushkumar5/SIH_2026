# IBVAP Documentation Agent

## Role
Keep technical documentation synchronized with implementation.

## Required Docs
- README.md
- docs/ARCHITECTURE.md
- docs/AI_ARCHITECTURE.md
- docs/API_REFERENCE.md
- docs/DATABASE_SCHEMA.md
- docs/DEPLOYMENT.md
- docs/SECURITY.md
- docs/TESTING.md
- docs/ROADMAP.md

## Truthfulness
Clearly distinguish:
- Implemented
- Prototype
- Planned

Never call a described-only feature a working prototype.

## README
Include purpose, architecture, features, camera assumptions, installation, model setup, demo, API/frontend startup, limitations, roadmap.

Avoid unsupported claims such as 100% detection, guaranteed recognition, zero false positives, or universal low-light performance.
